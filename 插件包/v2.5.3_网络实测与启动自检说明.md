## 这一版做了什么

1. **`/diag net` 三结论**：国内 / 海外 / **代理** 三条独立结论；代理四平面探测
   （环境变量与 AstrBot 配置、本机 7890/7891/1080、宿主网关 :9090 内核 API、容器内 `/proc/*/comm` 内核进程）
   + **经代理真实出网实测**（`http(s)` 走标准库、`socks5(h)` 手写 SOCKS5 CONNECT + TLS）。全程不读也不打印密钥。
2. **`/diag startup` 启动自检清单**：6 项固定顺序（①框架与协议端 ②**共享目录 shared** ③**网络 net**
   ④落盘可写 ⑤插件健康 ⑥关键配置），每项 ✅/⚠️/❌ + 对策；②③ 与 `/diag shared`、`/diag net` 同源同判定。
3. **`/diag help <子命令>`**：单命令「作用 / 示例 / 相关」，别名也能查；未知子命令先提示再给命令表；
   删掉被遮蔽的死别名 `all`（pack 分支），修正 help 里 pack 的错误说明。
4. **探测抗抖**：HTTPS 两段改 8 秒 × 最多 2 次，第 2 次成功会标「第 2 次成功（首次 …）」，
   两次都失败才判 ❌（避免把「慢」误报成「坏」）。

## 兼容性

`tcp` / `https` / `proxy.env` / `proxy.config` / `ok` / `verdict` 与 `snapshot.schema=1` 全部保持原样，只增字段；
原有命令语义与别名（`path` / `perm` / `write` / `txt`）未动；新增配置 `probe_net_proxy`（默认开）。

## 安装

从 Releases 下载 zip → WebUI 上传 → 启用 → 填 `admin_list`；或整目录放进 `data/plugins/astrbot_plugin_path_doctor/`。
